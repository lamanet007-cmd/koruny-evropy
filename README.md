# Koruny Evropy – Věk říší

Historická strategická hra pro webové prohlížeče.

## Technologie

- React
- TypeScript
- Vite
- Node.js
- Express
- SVG mapa

## Požadavky

- Node.js 20 nebo novější
- npm
- Git

## Instalace

V kořenové složce projektu spusť:

    npm install

## Vývoj

    npm run dev

Vite vypíše adresu lokálního vývojového serveru.
Obvykle jde o http://localhost:5173.

## Produkční sestavení

    npm run build

## Spuštění serveru

    npm start

## Ukládání

Aktuální prototyp ukládá rozehranou hru do
localStorage prohlížeče.

## Stav projektu

Verze 0.1.0 je hratelný technický prototyp.
Mapa je schematická a historická data jsou ukázková.
Nejde zatím o kompletní historickou simulaci Evropy.
